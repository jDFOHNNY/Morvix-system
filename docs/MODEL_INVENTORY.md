## Setup and evaluation

`requirements-ml.txt` lists the Python packages imported by the local model adapters, but does not pin a tested model/runtime version set. The source bundle does not include local model files, the previously referenced downloader/evaluation scripts, or a verified revision manifest. The backend loads snapshots from configured local paths with `local_files_only=True`; it does not download models during inference. The active project `.venv` imports `torch 2.14.1+cpu`, `transformers 5.20.2`, and `safetensors 0.8.0`, including the text model/tokenizer classes; full model compatibility is unverified because no approved text snapshot is present. Obtain the adviser-approved text and video snapshots, exact revisions, and tokenizer/processor assets from the team's trusted project source before attempting a model demonstration. Do not replace a snapshot or infer an image label order from weight names.

The expected text folder structure is `models/text/toxic-bert/` containing `config.json`, `model.safetensors` (or `model.safetensors.index.json` plus all named shards), and tokenizer data (`tokenizer.json` or `vocab.txt`). `tokenizer_config.json` and `special_tokens_map.json` should be preserved when they are part of the approved snapshot. The missing approval record and exact revision must be supplied before acquiring these files.

No MORVIX held-out evaluation dataset or evaluation script is present in this source bundle. Existing automated tests verify input handling, policy decisions, response behavior, and event persistence; they do not establish classifier accuracy. Report precision, recall, F1, or accuracy only after running a documented evaluation on labeled held-out examples.
